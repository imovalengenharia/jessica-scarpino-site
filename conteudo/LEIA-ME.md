# Como editar o site

Cada nota desta pasta é uma parte do site. Altere o texto, salve, e em poucos
minutos o site se atualiza sozinho (o Obsidian Git envia a mudança ao GitHub, que
publica o site).

## Regras simples
- O bloco entre os traços `---` no topo de cada nota são os **campos** (título, foto…).
  Mude só o que vem depois dos dois-pontos.
- Cada `## Título` vira um cartão (ou um passo, ou uma pergunta).
- Uma linha `icone: nome` logo abaixo do `##` escolhe o ícone do cartão. Ícones:
  coracao, livro, hospital, pessoas, onda, nuvem, brilho, maleta, folha, mensagem,
  alvo, casa, pergunta, cerebro.
- `==texto==` deixa o texto em destaque dourado.
- Fotos: coloque o arquivo em `Imagens/` e use `[[nome-da-foto.webp]]`.
- **Nova unidade**: duplique uma nota de `Unidades/` e troque nome, endereço e fotos.
- **Novo atendimento**: duplique uma nota de `Atendimentos/`; o campo `ordem` define a posição.
- Para tirar algo do site, apague a nota (ou a seção `##`).
